⚡ Layerly — Webpage to Figma

Turn any website into editable Figma layers in 3 simple steps!

🚀 Quick Setup Guide

1️⃣ Start Layerly

Mac: Double-click Start-Layerly.command

Windows: Double-click Start-Layerly-Windows.bat

⚠️ Keep the black window open while using Layerly!

2️⃣ Add the Plugin to Figma (One-time step)

Open Figma and open any project file.

Right-click on the screen → Plugins → Development → Import plugin from manifest…

Open the figma-plugin folder and select manifest.json.

3️⃣ Convert Your First Link!

Open the plugin in Figma (Plugins → Development → Layerly).

Paste any website URL (like https://google.com).

Click Convert & Import!

❓ FAQ

Plugin won't connect? Make sure the black window from Step 1 is still open.

Fonts look different? Install missing fonts on your computer or choose a replacement in Figma.
